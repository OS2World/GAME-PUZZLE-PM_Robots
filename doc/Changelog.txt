PM Robots - Changelog
=====================

1.6 (2026-10-20)
- New Options > Key Mapping... dialog: choose the mouse button that moves
  Smiley (default left) and the button that waits (default right), and the
  keys for Wait (W), Sonic Screwdriver (S) and Teleport (T); a button or key
  is never shared between two actions; Default restores the original ones
- The Game menu shows the mapped keys; a disabled menu item disables its key
- Mouse buttons and keys are saved in robots.cfg with the language
- New "Save settings on exit" item at the end of the Options menu, on by
  default (when it is off nothing is saved at exit)
- The dialog is translated in all six languages
- Fixed: makefile.wat now creates the bin folder (the build stopped when it
  did not exist)
- About dialog, BLDLEVEL string and documentation updated to version 1.6

1.5 (2026-09-10)
- Restructured menus: High Scores and Clear Scores moved to Options menu
- Removed Pause menu item
- Removed Background Run (not needed for this game type)
- Removed Save Settings on Exit (language now always saved on exit)
- Added keyboard shortcuts: S (Sonic Screwdriver), T (Teleport), W (Wait), Ctrl+N (New Game)
- Score/Level display right-justified in menu bar
- Fixed window sizing: client area now correctly sized using system metrics
- Fixed Frame Controls toggle (Ctrl+F) to properly restore title bar and menu
- Resolved all compiler warnings

1.4 (2023-06-09)
- Rebuilt with Open Watcom wcc386 compiler
- Restructured menus: Game / Options / Help standard layout
- Added standard keyboard shortcuts: Ctrl+X (Exit), Ctrl+P (Pause),
  Ctrl+B (Background Run), Ctrl+F (Frame Controls)
- Added 6-language support: English, Spanish, Dutch, German, French, Italian
- Added Options menu with Language submenu, Background Run, Frame Controls
- Added settings persistence to robots.cfg
- Added BLDLEVEL string
- Centered window on desktop at startup
- Moved help content to Help > How to Play
