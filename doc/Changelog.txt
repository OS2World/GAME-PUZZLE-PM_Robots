PM Robots - Changelog
=====================

1.4 (2023-06-09)
- Rebuilt with Open Watcom wcc386 compiler
- Restructured menus: Game / Options / Help standard layout
- Added standard keyboard shortcuts: Ctrl+X (Exit), Ctrl+P (Pause),
  Ctrl+B (Background Run), Ctrl+F (Frame Controls)
- Added 6-language support: English, Spanish, Dutch, German, French, Italian
- Added Options menu with Language submenu, Background Run, Frame Controls
- Added settings persistence to robots.cfg
- Added BLDLEVEL string
- Centered window on desktop at startup
- Moved help content to Help > How to Play
