DESCRIPTION
-----------
This program is a version of the classic UN*X game "robots" for
the OS/2 Presentation Manager.  The main idea is that you are chased
by robots, and the object is to make them crash into each other before
they get you.

It's Smiley against the Evil Killer Robots.  Smiley is hopelessly
outnumbered, but with your intellect, you might be able to save him.
Fortunately, for you and Smiley, the robots have the stupid habit of
crashing into each other in their pursuit.

Every time you make a move, the robots move a space closer to Smiley.

The tools available to you are a Sonic Screwdriver and a Teleporter
Device.  The Sonic Screwdriver obliterates all robots adjacent to
Smiley, but can only be used once per level.  The Teleporter Device
moves Smiley to a random open space, but each use risks landing next
to a robot (certain doom for Smiley).

Clicking the left mouse button moves Smiley in the direction of the
mouse pointer (a question mark means Smiley cannot move that way).
Available moves are shown by the green diamonds around Smiley.
Clicking directly over Smiley takes a turn without making a move.
The right mouse button is the same as pressing Wait.

Points are awarded as follows: 10 points for every robot that crashes
into another robot or into a heap, and 1 point for every robot
obliterated with the Sonic Screwdriver.  Bonuses are awarded for not
using the Sonic Screwdriver on a level (50 points) and for successful
teleports (1 point per visible robot).


CONTROLS
--------
Left mouse button   Move Smiley toward the pointer
Right mouse button  Wait (same as Game > Wait)
S                   Sonic Screwdriver
T                   Teleport
W                   Wait
Ctrl+N              New Game
Ctrl+X              Exit
Ctrl+F              Frame Controls toggle (borderless mode)

COMPILE INSTRUCTIONS
--------------------
This version is built with the Open Watcom wcc386 compiler and wmake.

Requirements:
  - Open Watcom C/C++ installed at c:\watcom or c:\watcom2
  - OS/2 Toolkit 4.5 installed at c:\os2tk45

To build, run from the project root on ArcaOS:

  compile-wat.cmd

Or directly:

  wmake -f makefile.wat all

Output is placed in bin\Robots.exe.
